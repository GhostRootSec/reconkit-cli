# Recon-CLI

Recon-CLI is a lightweight command-line tool for authorized OSINT and reconnaissance workflows.

Available here:
https://ghostpentest.gumroad.com/l/vxfuad

## What it does

Recon-CLI helps organize common reconnaissance and OSINT tasks from a command-line interface. It is built for ethical hackers, students, IT professionals, and security researchers working in legal labs, owned systems, or approved client engagements.

## Authorized use only

Recon-CLI is intended only for systems, domains, and targets you own or have explicit permission to test.
