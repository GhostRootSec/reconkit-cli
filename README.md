# Reconkit-CLI

Reconkit-CLI is a lightweight command-line tool for authorized OSINT and reconnaissance workflows.

Primary command name:
reconkit-cli

Available here:
https://ghostpentest.gumroad.com/l/vxfuad

## What it does

Reconkit-CLI helps organize common reconnaissance and OSINT tasks from a command-line interface. It is built for ethical hackers, students, IT professionals, and security researchers working in legal labs, owned systems, or approved client engagements.

## Authorized use only

Reconkit-CLI is intended only for systems, domains, and targets you own or have explicit permission to test.
